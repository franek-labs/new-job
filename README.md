# New Job

Working repository for career strategy, active opportunities, networking, resumes, separation planning, and job-search research.

## Structure

- `01_Strategy/` — positioning, target roles, compensation, narrative
- `02_Opportunities/` — company-specific notes and outreach
- `03_Resume_LinkedIn/` — resumes, LinkedIn content, bios
- `04_Network/` — contacts and outreach
- `05_Separation_TS/` — Tuff Shed separation notes and financial/benefits tracking
- `06_Research/` — market/company/role research
- `07_Work_Samples/` — sanitized portfolio material
- `archive/` — superseded material

## GPT Files

- `GPT_CONTEXT.md` — durable context for AI handoff
- `GPT_WORKING.md` — current priorities, open loops, recent decisions

Sensitive source documents remain local and are excluded from Git where appropriate.
